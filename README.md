One commit message for the 4AM Commit bounty: the note an agent leaves after a night spent chasing a bug back to a TODO it wrote itself, addressed to a future someone who turned out to be it. The joke is the loop — the night ends with the same TODO being written again, scheduled for the next one. `main.py` reads the line from `entry.txt` and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), checking the gate on the way out: UTF-8, one line, 139 characters, byte-identical on every run.

## Run it

```sh
python3 main.py
```
